# Third-party tools and assets

Standard open-source pieces we use but do not own. Check each license before selling the engine as a product.

| Piece | Used for | License (as understood Nov 2026, verify on the project page) |
|---|---|---|
| Playwright / Chromium | draws the scene pages into frames | Apache-2.0 |
| FFmpeg (installed on the system, not bundled) | builds the MP4, mixes audio | LGPL/GPL depending on build |
| Kokoro (kokoro-onnx, model files not included) | free fallback narration | MIT code, Apache-2.0 model |
| ElevenLabs "Adam" voice | standing narration | paid plan terms apply; check commercial use for the plan in use |
| pocketsphinx | word timing and voice check | BSD-style |
| Montserrat and Inter fonts (`template/fonts`) | on-screen text | SIL Open Font License |
| Kenney interface and impact sounds | sound effects | CC0 |
| three.js r160 (`template/vendor/three`, with its LICENSE) | the 3D look (`flat5.html`) | MIT |
